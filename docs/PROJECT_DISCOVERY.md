## SECTION H: TECHNICAL & PERFORMANCE RISKS

| Risk Category | Description | Mitigation Strategy |
| :--- | :--- | :--- |
| **Image Heavy Payload** | High-resolution truck and tool photos degrading mobile PageSpeed scores. | Use Next.js `<Image />` component with WebP/AVIF format auto-conversion, explicit width/height dimensions, and responsive `sizes` attributes. |
| **Layout Shift (CLS)** | Dynamic elements, late-loading web fonts, or interactive accordions causing shifts. | Reserve container aspect ratios, use font fallback metrics, and test against zero-shift standards. |
| **Font Fetching Failures** | External Google Fonts failing during offline builds or slow mobile connections. | Configure resilient font fallbacks in CSS with system-ui font stacks to ensure instantaneous zero-delay text rendering. |
| **Mobile Friction in Emergency** | Users in panic struggling to find tap targets or dial phone numbers quickly. | Implement fixed bottom mobile dock with oversized 48px+ touch targets and native `tel:` triggers. |
| **Accessibility Non-Compliance** | Insufficient color contrast on orange accent buttons or grey secondary text. | Strictly calibrate all button text and badges to achieve WCAG 2.1 AA 4.5:1 minimum contrast ratios. |

## SECTION I: ACCEPTANCE CRITERIA & QUALITY GATES

For all subsequent milestones, the project must satisfy these measurable criteria:

1. **Brand Integrity:** Retains verified company name, address (11015 Airport Rd), phone numbers, licenses (`DANIKPL839PF`, `DANIKPL745CD`), and signature blue/orange color identity.
2. **Build Cleanliness:** Zero ESLint warnings/errors; strict TypeScript compilation without `any` escapes; successful production build (`npm run build`).
3. **Core Web Vitals & Performance:**
   * Google PageSpeed Insights Mobile score >= 90.
   * Google PageSpeed Insights Desktop score >= 95.
   * Cumulative Layout Shift (CLS) < 0.05.
   * Largest Contentful Paint (LCP) < 2.5s.
4. **Responsive Integrity:** Flawless rendering with no horizontal scrolling across 320px (iPhone SE), 390px (iPhone 14/15/16), 768px (iPad Mini), 1024px (iPad Pro / Laptop), and 1440px+ (Desktop).
5. **Accessibility Standards:** Full semantic HTML structure (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`), valid ARIA attributes, keyboard-navigable interactive controls, and WCAG AA contrast.
6. **SEO Completeness:** Valid JSON-LD `PlumbingContractor` structured data, semantic heading hierarchy (`H1` -> `H2` -> `H3`), dynamic XML sitemap, and search-optimized meta tags.
7. **Version Control Discipline:** Professional conventional commits (`feat:`, `chore:`, `fix:`) pushed to verified GitHub repository `danika-plumbing`.
